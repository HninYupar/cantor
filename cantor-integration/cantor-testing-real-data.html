Cantor Performance Metric

This report compares the performance of CantorOnS3 using two approaches: S3 Select and Local Select. The tests run against real data collected by maiev, querying a fixed timeframe so both approaches read the same data. Performance is measured as the latency per operation, in milliseconds.

Test Cases

  • getAll — retrieve all events for the selected instance
  • getMetadataExactMatch — query events whose metadata contains a key with an exact value
  • getMetadataHighSelectivityMatch — query events with an ultra-selective metadata value (matches very few events)
  • getMetadataNotEqualMatch — query events whose metadata key does NOT equal a value
  • getMetadataPatternMatch — query events whose metadata key matches a wildcard pattern
  • getMetadataKeyExists — query events where a metadata key is present (any value)
  • getDimensionComparisonMatch — query events whose dimension key satisfies a comparison (e.g. >= a threshold)
  • getDimensionRangeMatch — query events whose dimension key falls within an inclusive range
